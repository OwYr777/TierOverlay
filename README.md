# TierOverlay

TierOverlay is a client-side Fabric mod for Minecraft that displays player tier information from MCtiers, PvPTiers, and Subtiers directly in-game.

It is not tied to NoRisk Client. The mod is built for normal Fabric client profiles on Minecraft 1.21.11 and should work with any launcher/client setup that can load Fabric mods and Fabric API.

## Features

- Tier badges in nametags, chat, and the tab list
- MCtiers, PvPTiers, and Subtiers support
- Configurable display modes, including specific gamemodes or best tier
- Adjustable left/right layout for different providers
- Custom tier colors and icon size
- In-game configuration menu with `/tiersbyowyr7`
- Client-side only, no server installation required

Some servers use custom chat, tab, or nametag systems, so display behavior can vary between servers. TierOverlay only changes what is rendered locally on your client.
